# Koto — ToDo UI mock

A static, browser-only prototype for the agreed ToDo MVP. It contains synthetic sample content only and does not connect to authentication, a database, or cloud storage.

## Preview locally

Open `index.html` in a browser. Changes are stored in that browser's localStorage.

## Included in this mock

- List and calendar views (month, week, year)
- Personal/shared view filters and a new-shared indicator
- Editable tabs and shared tags
- Create/edit/complete/archive/restore ToDos
- Optional start date, due date, and up to two image attachments (local preview only)
- Responsive Japanese UI

GitHub Pages is not enabled by this repository yet.
